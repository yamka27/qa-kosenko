Шпаргалка по гіту
Рятувальний набір
1.Зіпсував файл, хочу відновити версію файлу до останнього коміту -> git restore <file> -> гіт відкине всі зміни для цього файлу, файл стане таким як в останньому коміті
2.Зробив гіт адд для файлу, але потім передумав -> git restore --staged <file> -> Файл прибирається зі staging area, але зміни в папці залишаються
3.Побачив помилку в повідомленні чи щось забув, а коміт ще не запущенний -> git commit --amend -m "..." -> гіт перезапише з правильним текстом
4.При різкій зміні на другу гілку з незбереженими змінами -> git stash -> ховає зміни, не видаляє, а просто залишає на потім
5.Побачив якусь помилку чи конфлікт після мерджу -> git merge --abort -> гіт повертає все до початку мерджу
Fetch і Pull
6.Бажаю дізнатися чи є нові коміти, але не хочу чіпати свій код -> git fetch origin -> гіт завантажує інформацію про коміти , але не вливає їх у робочу папку
7.Бажаю і завантажити і підключити чужі зміни до себе -> git pull origin maim -> гіт робить фетч, а тоді відразу мердж у мою гілку
Історія файлу
8.Хочу переглянути хто й коли змінював файл -> git log --follow-- <file> -> гіт показує список усіх комітів, їх авторів та коли вони відбулися
9.Хочу побачити не лише хто й коли, а й що саме змінювалось у комітах -> git log -p -- <file> -> додається diff, де + це додавалось, а - видалялось.
Базові команди
10.Заплутався де я -> git status -> чіткий перелік яка гілка, список змінених файлів і підказка що робити далі
11.Огляд історії комітів без довгих повідомлень -> git log --oneline -> один рядок = хеш + повідомлення
12.Підготовка файлу до коміту -> git add <file> -> файл з робочої папки в stage, гіт запам'ятовує що цей файл буде в некст коміті
13.Хочу додати всі файли відразу до коміту -> git add . -> всі файли в стейджі
14.Додавання повідомлення до конкретного коміту -> git commit -m "Add ..." -> коміт з повідомленням (локальним)
15.Поширення комітів для команди -> git push origin <branch> -> локальні коміти стають видимими для всіх в окремій гілці.
16.Створення гілки і відразу перехід до неї -> git checkout -b <branch> -> створюється гілка і робота тепер відбувається в ній
17.Повернення на основну гілку -> git checkout main -> гіт перемикає на основну гілку, якщо немає незбережених змін
18.Хочу подивитися що я змінив у файлі після останнього коміту -> git diff -> гіт показує різницю між стейджом і робочою папкою
19.Перегляд усіх гілок у репозиторії та на якій я зараз -> git branch -> гіт показує всі локальні гілки та відмічає поточну гілку
20.Для початку роботи з репозиторієм -> git clone <url> -> гіт копіює весь репозиторій з гітхабу
