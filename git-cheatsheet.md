## Рятівний набір

- Зіпсував файл, хочу відновити версію файлу до останнього коміту → git restore <file> → гіт відкине всі зміни для цього файлу, файл стане таким як в останньому коміті
- Зробив гіт адд для файлу, але потім передумав → git restore --staged <file> → Файл прибирається зі staging area, але зміни в папці залишаються
- Побачив помилку в повідомленні чи щось забув, а коміт ще не запушений → git commit --amend -m "..." → гіт перезапише з правильним текстом
- При різкій зміні на другу гілку з незбереженими змінами → git stash → ховає зміни, не видаляє, а просто залишає на потім
- Зберіг зміни в stash і хочу повернути їх назад у робочу директорію → git stash pop → гіт дістає останньо збережені зміни зі stash і застосовує їх
- Побачив конфлікт під час мерджу і хочу скасувати злиття → git merge --abort → гіт повертає все до початку мерджу, як будто його не було

## Fetch і Pull

- Бажаю дізнатися чи є нові коміти, але не хочу чіпати свій код → git fetch origin → гіт завантажує інформацію про коміти, але не впливає їх у робочу папку
- Бажаю і завантажити і підключити чужі зміни до себе → git pull origin main → гіт робить фетч, а тоді одразу мердж у мою гілку

## Історія файлу

- Хочу переглянути хто й коли змінював файл → git log --follow -- <file> → гіт показує список усіх комітів, їх авторів та коли вони відбулися
- Хочу побачити не лише хто й коли, а й що саме змінювалось у комітах → git log -p -- <file> → додається diff, де + це додавалось, а - видалялось.

## Базові команди

- Заплутався де я → git status → чіткий перелік яка гілка, список змінених файлів і підказка що робити далі
- Огляд історії комітів без довгих повідомлень → git log --oneline → один рядок = хеш + повідомлення
- Поправив файл і хочу щоб саме він пішов у наступний коміт → git add <file> → файл з робочої папки в stage, гіт запам'ятовує що цей файл буде в некст коміті
- Хочу додати всі файли відразу до коміту → git add . → всі файли в стейджі
- Вже зробив коміт але забув додати файл — хочу додати його в останній коміт без нового → git commit -m "Add ..." → коміт з повідомленням (локальним)
- Зробив кілька комітів локально і хочу відправити їх всі на GitHub → git push origin <branch> → локальні коміти стають видимими для всіх в окремій гілці.
- Створення гілки і відразу перехід до неї → git checkout -b <branch> → створюється гілка і робота тепер відбувається в ній
- Повернення на основну гілку → git checkout main → гіт перемикає на основну гілку, якщо немає незбережених змін
- Хочу побачити всі зміни після останнього коміту (включно зі staged) → git diff HEAD → гіт показує різницю між останнім комітом і робочою папкою
- Перегляд усіх гілок у репозиторії та на якій я зараз → git branch → гіт показує всі локальні гілки та відмічає поточну гілку
- Отримав посилання на репо і хочу почати роботу з ним локально → git clone <url> → гіт копіює весь репозиторій з гітхабу
